# 지구과학Ⅰ 자체 제작 교과서 사양 (2026-05-06, Phase 1 P1-EARTH)

## 배경 및 목표

소크라테스 튜터(`/tutor`) + 마인드맵(`/mind-map`)은 현재 3 과목만 보유 — 생활과 윤리 / 언어와 매체 / 생명과학Ⅰ. 사용자 결정 (2026-05-06) 으로 **지구과학Ⅰ을 4번째 자체 제작 과목**으로 추가한다.

- 분량 목표: **약 200 페이지 (≈ 400K 자)** — 생명과학Ⅰ 수준의 교과서 완전 정리
- 패턴: 헤밍웨이 v2 가 아닌 **기존 ethics/biology/korean 패턴** 재사용 (TS 객체)
- 통합: 소크라테스 튜터 SUBJECTS 추가 + 마인드맵 SubjectKey 확장 + 두 도구가 같은 textbook 데이터 공유 (1:1)

## 출처 / 교육과정 기반

2022 개정 교육과정 (현행) 지구과학Ⅰ + 일부 지구과학Ⅱ 핵심 — 수능·내신 빈출 단원 우선.

대단원 3개를 5 chapter 로 재구성 (소크라테스 튜터의 5 topic 슬롯과 1:1 매칭).
